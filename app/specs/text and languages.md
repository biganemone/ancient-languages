# Sanskrit
* In an ideal world, we'd support both translitered Sanskrit and Devenangari (spelling?). That part shouldn't be too hard - if you have one, you should be able to get to the other. The main thing is can we get parsed texts and a lexicon?
  * Traditionally the Bhagavad Gita is the starting text, which is also what we'd want. 

# Hebrew

* If we can get a parsed Hebrew Bible, a good font, support left to right writing, and a solid lexicon we'd do it. Not sure if you'll find all of that or not. 

# Latin

# Thoughts on Default Texts per Language

## Hebrew
Just the Hebrew Bible, naturally

## Greek
The NT, The Iliad & the Odyssey, a light sample of Plato, Antigone, Herodotus, Marcus Aurelius

## Latin
The Vulgate, The Aenied, probably some Cicero, some Tacitus, Ovid's Metamorphoses

## Sanskrit
The Bhagavad Gita if we can get it, a sprinkling of the principal Upanishads

## Coptic
The Gospel of Thomas

## Old English
Beowulf

## Other languages 
If we add other languages (e.g., Norse or Assyrian) consider making the whole language downloadable, depending on how much space we have

Old Norse (added Nov 2026) is the first fully downloadable language: the Poetic Edda, the Prose Edda, Njáls saga and Egils saga download as texts, and Zoëga and Cleasby–Vigfússon as a dictionary module with the first of them. Nothing of it ships with the app.
